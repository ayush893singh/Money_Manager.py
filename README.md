# Money_Manager.py
A simple command-line based Money Tracker built using Python.
This project allows users to create expense trackers, add expenses, and view total spending in an organized way.

## Features
Create multiple Money Tracker
Add expense items with amount
Automatic total expense calculation
Menu-driven interface
Input validation using try-except
Beginner-friendly Python project

## Technology Used
Programming Language: Python 3

## Concepts Used:
```
*Functions
*Lists
*Dictionaries
*Loops
*Conditional Statements
```
## How It Works
Step 1 – Start Program
The program displays a menu:

1. Add Tracker
2. View Trackers
3. Exit

Step 2 – Add Tracker
User enters:

Tracker name
Expense item name
Expense amount

The program stores all expenses inside a tracker.

Step 3 – View Trackers
The program displays:

Tracker name
All expense items
Expense amounts
Total spending

Step 4 – Exit
Program ends safely.

## How to Run
Method 1 – Using Terminal
Step 1
Install Python 3 from:
Python Official Website

Step 2
Save the file as:
Money_Manager.py

Step 3
Open terminal in folder.

Step 4
Run the program:
python Money_Manager.py
